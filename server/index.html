Aerial Screensaver video server

A local mirror of the Apple TV aerial videos, served on the home network so the Tizen app on the TV streams from here instead of Apple's CDN.

1. Point the app here

In the app's Settings turn on Custom server and set the URL to this server, for example http://192.168.2.4:8090.

2. Files are direct

Every video is a plain file at /<name>.mov. Range requests and CORS are on, so any player or browser can stream them.

3. Thumbnails

Preview stills live under /thumbnail/<name>.jpg.
